# Study Spark

Study Spark — персональное приложение для учёбы и мотивации. Создавайте учебные задания, проводите Pomodoro-сессии, зарабатывайте звёзды и обменивайте их на собственные награды.

## Возможности

- Учебные задания со сложностью, наградой, дедлайном и статусом.
- Pomodoro-таймер с настраиваемой длительностью фокус-сессии, перерыва и награды.
- Баланс звёзд и уровни прогресса.
- Магазин с пользовательскими наградами и категориями.
- История заработанных и потраченных звёзд.
- Имя профиля и настройки приложения.
- Адаптивный интерфейс для компьютеров и телефонов.

## Требования

- Node.js и npm.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте URL, показанный Vite в терминале (обычно `http://localhost:5173`). Не открывайте `index.html` напрямую через `file://`: приложение использует React и Vite-модули.

## Сборка

```bash
npm run build
npm run preview
```

Production-файлы создаются в каталоге `dist/`. Команда `preview` запускает локальный просмотр этой сборки.

## Деплой на Vercel

Подключите Git-репозиторий проекта к Vercel. Для Vite используйте следующие параметры сборки:

- **Build command:** `npm run build`
- **Output directory:** `dist`
- **Install command:** `npm install`

Backend и база данных проекту не нужны. Для клиентского приложения с одной страницей дополнительных rewrite-правил не требуется.

## Хранение данных

Пользовательские данные сохраняются в `localStorage` браузера. Они остаются на устройстве и в профиле браузера, где вы открыли приложение. Размещение приложения на Vercel публикует сам сайт, но не синхронизирует данные между браузерами или устройствами. Очистка данных сайта в браузере может удалить сохранённое состояние.

Приложение использует ключ `study-spark-v1` в `localStorage`. Чтобы вручную сбросить данные, удалите этот ключ в инструментах разработчика браузера в разделе **Application/Storage → Local Storage** для адреса сайта.

## Установка как приложение

Study Spark поддерживает установку как PWA на устройствах и в браузерах, которые её поддерживают. На сайте откройте меню профиля → **Скачать приложение**. Если браузер предлагает установку напрямую, подтвердите её; иначе следуйте инструкциям в окне.

После первого посещения приложение кэширует оболочку и файлы интерфейса для офлайн-запуска. Установка доступна на `localhost` для разработки и на HTTPS-домене при публикации на Vercel.
